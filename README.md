## 第一部分：书籍分类标准 (Classification Domain)

### 1. 核心分区目录结构

- **集选传回忆录**：主要收纳各领域人物的传记、作品集、文集、语录及人生回忆录等综合性文本。

- **历史与社会研究**：包含具体国家或地区的研究主题文件。
  - **东亚南亚分区**：收纳东亚、东南亚、南亚地区（除中国、俄罗斯、印共毛外）的政治、历史及社会研究资料（如朝鲜、柬埔寨、越南、菲律宾、日本、印度等）。
  - **俄罗斯(前苏联)**：苏联及当代俄罗斯相关研究。
  - **西欧北美分区**：收纳西欧及北美地区（主要为美、英、法、德、意、西）的政治、历史及社会研究资料。
  - **其它国家及国际问题**：包含古巴、拉丁美洲、西亚北非（如土耳其、利比亚、巴勒斯坦）及国际共产主义运动通史、跨区域国际问题。
  - **中国**：
    - **古代史**：1840年之前的中国历史，包括各朝代政治、官僚制度、医学史等。
    - **近代史**：收纳民国史资料、国民党史（1840年至1949年之前）。
    - **共和国前三十年**：1949-1978年间的历史内容。
      - **大跃进与困难时期资料**：大跃进运动、困难时期、饥荒真相及1958-1962年间的路线斗争。
      - **文革运动史与各省动态资料**：文化大革命的核心历史、各省市运动动态、武斗资料及运动通史研究。
      - **跃进文革时期其它资料**：文化、艺术与社会建设（小说、诗选、样板戏、电影评论、考古、医疗及科技成就等）。
      - **保皇派及中派合集**：文革时期保皇派、中派人物及相关组织（明确将**周恩来**相关文件归属为“中派”）。
      - **造反派及温和派合集**：文革时期造反派及温和派人物相关（核心运动组织、上海三司、清华井冈山等）。
      - **林彪集团**：林彪相关内容。
    - **历史综合研究资料**：跨越较长时段的历史综合研究、党史教材、党章及组织建设资料等。
    - **改革开放与当代史**：1978年以后的中国历史，包括改革年代政治、当代维稳研究及80年代思想启蒙。
    - **八九六四**：8964相关历史。
    - **工农运动与社会调查**：收录各类农村/工人群体实证研究、社会调查与运动分析。
    - **儒法斗争**：批判旧儒学。

- **其它作品及论文**：非核心社科的正常文本，包括文学与艺术、心理学、科普等。

- **社会意识**：哲学、政治思想、意识形态相关文本。
  - **后现代与当代欧陆哲学**：福柯、德勒兹、齐泽克、巴迪欧及 Tiqqun/隐形委员会等当代激进理论。
  - **经济学**：劳动经济学、政治经济学（含《资本论》相关）及当代经济分析。
  - **马恩列斯毛经典著作**：经典马主义作家原著文本、语录、个人文集。
  - **马克思主义哲学**：其他著名作家的马主义理论文本。
  - **西方古典哲学**：黑格尔、谢林、尼采等德国观念论及古典逻辑学。

- **社科当代论**：收录当代左翼互联网讨论与实践的档案馆。

- **数据资料等**：经济、人口统计等各类硬性数据。

- **杂乱文件**：互联网奇怪搞笑文件、低质产物、各种格式的图片影片音频等。

### 2. AI 语义识别操作准则 (AI Skill Core)

- **整体感知原则**：严禁仅依赖文件名中的孤立关键词（如“手册”、“革命”）进行筛选。必须将文件名作为一个完整语义对象，结合文件所在路径，判断其在知识库中的逻辑归属。
- **语境锚定与代称识别**：AI需具备识别特定谐音或借代的能力：
  - “猫” -> 毛泽东；“稻/凳” -> 邓小平；“桥春张” -> 张春桥。
  - 需根据作者写作时的身份属性进行分类（如周恩来总理身份的报告属“共和国史”，文革时期活动属“中派”）。
- **内容复核机制**：若文件名语义模糊或存在歧义（如chm文件），AI应使用工具读取文件（如pypdf提取前3-5页目录/序言）进行辅助判断。
- **分类优先级与兜底**：
  - **精确映射**：优先寻找一对一的精确路径。
  - **父目录兜底**：若无法精确细分到子文件夹，严禁强行归类，应直接存放在符合宏观属性的父文件夹。
  - **跨学科处理**：齐泽克、巴迪欧等激进理论归入“社会意识/后现代与当代欧陆哲学”，而非“社科当代论”。
  - **理论 vs 著作**：基础学科理论（如资本论）放“经济学”；个人语录、生平放“马恩列斯毛经典著作”或“集选传回忆录”。
- **社科当代论内容范畴**：
  该文件夹主要收录当代左翼互联网讨论与实践的相关内容，其核心板块包括：
  1. 历史辩论与“辟谣”类文件。
  2. 当代左翼领军人物/大V的作品集。
  3. 社会热点事件的阶级分析。
  4. “亚文化”攻防战（非常独特的板块）。
  5. 实践手册与路线指南（系统性学习辅助/实践指导文件）。
  6. 圈内“论战”与“挂人”记录。
